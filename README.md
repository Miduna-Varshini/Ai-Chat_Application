# 🤖 Groq AI Chat

A simple AI chatbot built with Streamlit, Groq, and Supabase.

## Features

* Real-time AI responses using Groq LLM
* Streaming chat interface
* Persistent chat history with Supabase
* Multiple chat sessions
* Clean and responsive Streamlit UI

## Tech Stack

* Python
* Streamlit
* Groq API
* Supabase

## Usage

1. Add your Groq API key to the `.env` file.
2. Run the application with Streamlit.
3. Start chatting with the AI assistant.
